# Security Policy

## Supported Versions

`lsr` is pre-1.0 and is developed on `main`. Only the most recent release
receives security updates; there are no maintained older branches.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/fxrdhan/lsr/security/advisories/new)
for this repository, which opens a draft security advisory visible only to the
maintainer. Include the version (`lsr --version`), your platform, and the steps
needed to reproduce the issue.

Please do not open a public issue for a suspected vulnerability.

`lsr` is a fork of [eza](https://github.com/eza-community/eza). If the issue is
in code inherited from upstream and affects eza as well, please also report it
to the [eza security policy](https://github.com/eza-community/eza/blob/main/SECURITY.md)
so users of both projects are covered.
